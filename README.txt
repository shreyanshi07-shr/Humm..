humm.. : how to put it on your home screen

1. Host this folder on any https site (free options: Netlify Drop at app.netlify.com/drop:
   drag this whole folder in; or GitHub Pages; or Vercel).
2. Open the link on your phone.
   Android (Chrome): menu ⋮ → "Add to Home screen" / "Install app".
   iPhone (Safari): Share → "Add to Home Screen".
3. It opens full-screen from the humm.. icon, and keeps working offline.

Opening the .html straight from WhatsApp/Files can't be installed: phones only install apps from a web link.

App icon
The icon is the blue "humm.." wordmark (folder: icons).
Prefer the earbuds doodle? Delete the "icons" folder, rename "icons-earbuds" to "icons", upload again.
(The iPhone icon and tab favicon are also built into index.html as the wordmark.)
