humm.. : what's in this folder

Upload everything here to GitHub (Vercel deploys it):
  index.html, sw.js, manifest*.webmanifest, icon / badge pngs.
supabase-setup.sql is for the Supabase SQL Editor (not needed on Vercel, harmless if uploaded).

Phone notifications also need the small "notify" function in Supabase.
The steps (and your secret keys) are in "notifications-setup.txt", which is sent separately.
Never upload notifications-setup.txt to GitHub.
